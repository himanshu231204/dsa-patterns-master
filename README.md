# 🧠 Pattern 1 – Two Pointer

## 📖 Concept
Two pointers traverse an array intelligently to reduce time complexity from **O(n²) → O(n)**.

### 🧩 Pattern Types
1. Opposite Direction  
2. Slow–Fast Pointer  
3. Fixed + Two Pointer  
4. Greedy + Optimization
